# Tools: Icons

A pretty simple script to render SVG and PNG icons based on basic configuration (found in
`icons.json`). The icons themselves are pulled from [pixelarticons][1], or local custom icons.
Where pixelarticons are used, only the free icons from the base set are used.

## Usage

Run `npm install`, and render with `npm run render`.

[1]: https://www.npmjs.com/package/pixelarticons
